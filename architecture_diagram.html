EYESENTINEL Architecture

AI-Powered Retinal Triage & Glaucoma Screening System Flow

1. Ingestion & Prep

Loads retinal fundus images from the Kaggle dataset repository, structures metadata using Pandas, and initializes data generators.

2. Deep Learning Core

Custom 3-layer Convolutional Neural Network (CNN) trained with binary cross-entropy loss, achieving 91.27% validation accuracy.

3. Presentation Layer

Streamlit-powered cyber-dark interactive dashboard equipped with live image uploader and real-time clinical probability scoring.
